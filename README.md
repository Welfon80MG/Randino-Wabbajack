# Randino-Wabbajack
Randino Skyrim SE modlist.

## Game Version

Randino requires Skyrim Special Edition runtime **1.6.1170.0**.

Do not install or launch Randino with Skyrim runtime 1.7.x. Verify the version of `SkyrimSE.exe` before installing the modlist.

## Important
Randino is a curated modlist.

After installation:

- Do **not** run LOOT.
- Do **not** sort the plugins yourself.
- Do **not** update individual mods unless an update is specifically approved for Randino.
- Do **not** regenerate DynDOLOD, TexGen, xLODGen, Requiem, Pandora, Synthesis, or other generated outputs unless you are intentionally modifying the list.
- Do **not** remove mods because they appear redundant without first understanding their purpose.
- Always launch Skyrim through the Mod Organizer 2 installation supplied with Randino.

Changing the list may cause crashes, broken quests, visual problems, missing terrain, patch conflicts, or save-game issues.
